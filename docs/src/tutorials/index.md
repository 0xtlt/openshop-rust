# Tutorials

Follow these lessons in order. Each one gives you a working result and tells you
what to look for before continuing. They assume basic Rust and terminal
experience; no previous OpenShop experience is needed.

| Lesson | What you will build | Before you start |
| --- | --- | --- |
| [1. Build your first app](first-app.md) | An embedded app that reads Shopify orders and calls a sample provider | Rust 1.88 or newer, Docker (for PostgreSQL 17), Shopify CLI, and a development store |
| [2. Build a checkpointed flow](checkpointed-flow.md) | A small job that pauses and resumes without repeating completed work | The running app from lesson 1 |

Already have an app and a specific task? Use the [how-to guides](../guides/index.md).
To understand what you built, read [Building blocks](../concepts/building-blocks.md).
